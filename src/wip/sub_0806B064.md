## Role

Text-width measure over a 0xDC-stride item array (`struct Unk6B3E8`, extended in
`include/unknown-types.h` for this function: `unk00` item base, `unk04` count,
`unk10` string, `unk24` s16 scale, `unk28` kerning table base; item gains
`unk10` glyph width, `unk22` s16 kerning index, `unk70` flag).

```
total = 0; spaces = 0;
for (i = 0; i < a->unk04; i++) {
    item = &a->unk00[i];
    if (a->unk10 != 0 && a->unk10[i + spaces] == ' ') { total += 5; spaces++; }
    if (item->unk70 != 0) {
        if (a->unk28 != 0) total += item->unk10 - kerning[item->unk22];
        else               total += item->unk10;
    }
}
return (a->unk24 * total) >> 8;
```
