## Current state

94/96 same-size. The only delta is the pool load destination:

```
retail:   ldr r0, _080739E4  ; adds r0, r1, r0
compiled: ldr r2, _080739E4  ; adds r0, r1, r2
```

Retail's allocator loads `0x080BB748` straight into the destination register r0;
agbcc puts the constant in r2 and adds. Semantically identical, and every source
shape that removes the `index =` side effect re-colours r7/r12 and drops to 89/96.
