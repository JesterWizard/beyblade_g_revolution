## Role

Walk a string and accumulate `delta - kern[table[ch]]` (skip 7/8/10; space adds `space`).

## Register coloring

Seven values stay live across the loop (`text, base, delta, space, index, total, ch`). Retail puts them in `r4,r7,r6,r5,r2,r3,r1` and uses `r0` as scratch for the table load.

agbcc 2.9 prefers to put **base in `ip`** and the **table constant in `r7`** (`mov r12,r1` / `ldr r7,=table` / `add r0,r1,r7` / `add r0,r12`) — 89/96.

`r0 = (index = 0x080BB748)` occupies r2 with the table, which frees r7 for base. Prologue then matches, but the load is `ldr r2` / `add r0,r1,r2` — **94/96**.

Split load then smash:

```
r0 = 0x080BB748;
index = 0x080BB748;
r0 = ch + r0;
```

emits `ldr r0` / `adds r2,r0,#0` / `adds r0,r1,r0` — **correct dest, extra 2-byte copy** (98B, scores as 62/96 size_mismatch).

Need table in r0 **and** index still in r2 **and** base in r7, with no extra copy. `if (var) {}`, masks, `-ffixed-r12`, `-fregmove`, declaration/copy grids, struct SRA, and permuter (score 10) did not get there.

## Current state

94/96. Table `ldr` dest r2 vs r0; base is already r7.
