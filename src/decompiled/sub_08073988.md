## Current state

Readable seed: pointer walk and a `switch` on 7 / 8 / newline / space. The 94/96
goto seed is no longer in the `.c`. Its only delta was the pool load destination:

```
retail:   ldr r0, _080739E4  ; adds r0, r1, r0
compiled: ldr r2, _080739E4  ; adds r0, r1, r2
```

Retail's allocator loads `0x080BB748` straight into the destination register r0;
agbcc puts the constant in r2 and adds. Semantically identical, and every source
shape that removes the `index =` side effect re-colours r7/r12 and drops to 89/96.

## 2026-09-24 — suggestion-list sweep (idiom / restructure / micro-grammar)

Worked all three unlock paths from the permuter post-mortem:

1. **C idiom for `ldr r0,=pool`** — `index = (r0 = 0x080BB748); r0 = ch + r0;` *does*
   emit `4807` / `1808` (`ldr r0,…; adds r0,r1,r0`) but **also** emits
   `adds r2,r0,#0` materialising the `index = …` store. That costs ~34 bytes of
   branch/regalloc drift (62/96). Every attempt to drop the `r2` copy while keeping
   `ldr r0` either reverts to `ldr r2` (94/96) or `ldr r7` (89/96).
2. **Restructure without an `r0` chain** — `acc`/`addr`/`pool` locals with
   `(index = C)` side effect: all 94/96, still `ldr r2`. Without the side effect:
   89/96 (`ldr r7`, `base` moves off `r7`).
3. **Targeted micro-grammar** — 50+ first-line shapes (`void index`, comma forms,
   `tmp[]`, `gData_080BB748`, fn-scope `glyph_table`, split `pos`/`index`, …) in
   `build/sweep_73988_default_char.py` + `build/sweep_73988_pool_r0.py`. **No
   `96/96`.** Best remains baseline / side-effect family at **94/96**.

**Triangle (agbcc):** `(index = pool)` preserves the r4–r7 frame but pools into **r2**;
`index = (r0 = pool)` pools into **r0** but must clobber **r2**; splitting `index` off
`r2` loses the `ldr r0` idiom entirely.
