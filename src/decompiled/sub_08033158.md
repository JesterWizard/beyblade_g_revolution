## Role

Normalises `a` against `b` by repeatedly halving `b` (arithmetic — `b` is **signed**) until `r <= b << 8`, then returns `b` scaled back to Q8, or `1` when the loop ran `b` down to zero.

## Current state

Retail and compiled agree byte-for-byte except one branch offset:

```
0x12: cmp  r1,#0
retail:  0x14: beq +5  -> 0x22 movs r2,#1    (threads past the dead copy)
compiled:0x14: beq +2  -> 0x1C adds r2,r1,#0
```

The loop-exit edge (`b == 0`) makes `r = b` dead, so retail's compiler redirects the
branch straight to `movs r2,#1`. agbcc emits the block-entry target instead. Adding
the `movs` target explicitly (duplicating `r = 1`, `goto`) changes the layout by
size, so this is **jump threading**, not a source-order detail.
