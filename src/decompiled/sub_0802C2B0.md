## Role

Clears the "taken" flag on every `Unk1694` record whose key matches `a`, then marks
the record selected by `b` as taken.

## Process

- 2026-09-21 — 9 further variants over the two remaining deltas: tail sum order
  (`(u8*)base + off`, `keyoff + (u32)base` accumulated into a `u32 addr`, struct-member
  `&(*loc)->unk1694[i]` form), plus prologue pointer plumbing (`loc`/`loc_load`
  assignment order). Best stays 92/100; the plus-operand order is canonicalised by GCC,
  so the `adds` encoding does not flip.

## Current state

92/100 same-size, two 2-byte deltas that are both allocator/scheduling choices:

```
(a) retail   ldr r4,=0x1694 ; adds r0,r0,r4 ; ldr r0,[r0] ; mov r12,r1
    compiled ldr r4,=0x1694 ; mov r12,r1   ; adds r0,r0,r4 ; ldr r0,[r0]

(b) retail   adds r1, r1, r0      (Rn = offset, Rm = base)
    compiled adds r1, r0, r1      (Rn = base,   Rm = offset)
```

`(b)` is the same value with the two source registers swapped in the encoding; it
cannot be steered by writing `off + base` instead of `base + off`.
